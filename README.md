# Urooj Mahmood — Portfolio Website

A responsive, single-page portfolio built with HTML, CSS, and vanilla JavaScript.

## Included
- `index.html` — all portfolio sections and content
- `css/style.css` — responsive styling and visual design
- `js/script.js` — mobile navigation, project filters, reveal animations, and current footer year
- `images/` — place your profile and project images here
- `Urooj_Mahmood_CV.pdf` — add your CV PDF here for the Download CV link to work

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a browser, or open the folder in Visual Studio Code and use Live Server.
3. Add your CV PDF named exactly `Urooj_Mahmood_CV.pdf` in the root folder.
4. If you add a profile image, put it in `images/` and update the HTML accordingly.

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `urooj-portfolio`).
2. Upload the contents of this folder to the repository root.
3. Open **Settings → Pages** in the repository.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.

## Personalization checklist
- Verify dates, project details, certifications, and education information before publishing.
- Add real repository links to each project if available.
- Add your CV PDF in the root folder.
- Add an image in `images/` and update the hero if you want to show a portrait.
- Check that all links and downloads work on desktop and mobile.

The Google Fonts import requires an internet connection; the site falls back to system fonts when unavailable.
